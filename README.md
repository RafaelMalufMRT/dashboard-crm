# Máquina de Vendas MRT — apresentação

Relatório visual dos fluxos comerciais inbound e outbound, incluindo:

- etapas totalmente automatizáveis;
- etapas automáticas com aprovação;
- atividades assistidas e humanas;
- limitações das integrações;
- roadmap recomendado.

## Publicação

O projeto é um site estático sem dependências. O arquivo `index.html` pode ser publicado diretamente pelo GitHub Pages ou pela Netlify.

## Uso local

Abra `index.html` no navegador. Pressione `P` para entrar no modo de apresentação, use as setas para navegar e `Esc` para sair.
